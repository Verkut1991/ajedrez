# Ajedrez

A small Android chess app for when you want a real game without opening a browser or logging into anything. Open it on your phone, tap a piece, see where it can go, and play.

The board and the rules live on the device. There is a light AI opponent with a few difficulty levels, options for name and feel, and a stats screen for after the game. Nothing online — just local chess for a quiet stretch of minutes.

> Local demo. Open the project in Android Studio and run it on an emulator or a phone.
